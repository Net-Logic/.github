**Net-Logic** builds, integrates and maintains [Dolibarr ERP CRM](https://www.dolibarr.org) for companies, and publishes Dolibarr modules on [DoliStore](https://www.dolistore.com). Based in Noisy-le-Grand, France.

[Website](https://www.netlogic.fr) · [Module documentation](https://wiki.netlogic.fr) · [dolibarr@netlogic.fr](mailto:dolibarr@netlogic.fr)

<br clear="left">

## Open-source tools

| Repository | What it does |
| --- | --- |
| [dolistore-sync](https://github.com/Net-Logic/dolistore-sync) | GitHub Action publishing a module release to its DoliStore product (zip, texts in 5 languages, screenshots) |
| [wiki-sync](https://github.com/Net-Logic/wiki-sync) | GitHub Action generating a module's [wiki](https://wiki.netlogic.fr) page from the `wiki/` folder of its repository |
| [lowa-build](https://github.com/Net-Logic/lowa-build) | LibreOffice for WebAssembly build recipe, the engine of Office Editor |
| [github-dolibarr-action](https://github.com/Net-Logic/github-dolibarr-action) | GitHub Action building a Dolibarr module package |

We also contribute to [Dolibarr](https://github.com/Dolibarr/dolibarr) itself.
